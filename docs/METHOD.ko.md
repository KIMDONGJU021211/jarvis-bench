# 방법

## 과제

한 판 = 한국 사이트에 가서 조사하고 **파일로** 정리하는 부탁 하나. 부탁 문장은 `bench/multiturn_bench.py` 의
`TASKS`(고치며 돌린 5과제)와 `HOLDOUT`(결과 보기 전에 박아 둔 5과제)에 그대로 있다.

| 과제 | 사이트 | 형식 |
|---|---|---|
| wishket_xlsx | 위시켓 | 엑셀 |
| yes24_md | YES24 | 마크다운 |
| saramin_doc | 사람인 | 문서(워드·한글·마크다운·엑셀 중) |
| resume_skill | 사람인 | 이력서 초안(산문) |
| competitor_skill | 위시켓 | 경쟁 분석 문서 |
| *danawa_csv* | 다나와 | CSV |
| *jobkorea_hwpx* | 잡코리아 | 한글(HWPX) |
| *aladin_docx* | 알라딘 | 워드 |
| *musinsa_xlsx* | 무신사 | 엑셀 |
| *kyobo_yes24_md* | 교보문고+YES24 | 마크다운(두 사이트 비교) |

## 에이전트 조건

- 두뇌: Gemma 4 26B QAT (Ollama, RTX 3090), 컨텍스트 128K. 클라우드 모델 없음
- 브라우저: 실제 크롬. 로그인·결제·캡차 앞에서는 멈춘다(규칙)
- 판 예산 900초. 벤치 중에는 만든 파일을 창으로 띄우지 않는다
- 판이 끝나면 만든 파일을 **바로** 떠 둔다 — 같은 이름을 다음 라운드가 덮기 때문이다

## 채점 셋

### 1. 사슬 (multiturn_bench.py)

한 판 안에 읽기 도구(`browser_extract` 등)와 쓰기 도구(`local_write_document` 등)가 **둘 다** 있나.
그리고 판 도중에 쓰인 파일이 시킨 형식인가.

### 2. 표 칸 채움 (content_grade.py)

- 과제마다 **시킨 행 수와 열**을 프롬프트에서 옮겨 적었다(`WANT`). 열 이름은 낱말 후보 묶음으로 찾는다
- 분모는 **시킨 것**이다(3건 × 4열 = 12칸). 적게 만들면 분모가 줄지 않는다
- 「확인 불가」「N/A」「-」 같은 칸은 채운 것으로 안 센다
- 형식별로 표를 꺼낸다: xlsx · docx · md(파이프·탭) · **쉼표 CSV** · **한글(HWPX)은 XML 에서 행·칸 구조째**

### 3. 양식·근거 (doc_form.py)

기준을 새로 지어내지 않았다. **에이전트에게 문서를 쓰라고 가르친 규칙**을 그대로 잰다.

| 항목 | 무엇 |
|---|---|
| 형식 | 시킨 확장자 |
| 제목 | 첫머리에 제목(H1) |
| 요약 | 한 줄 요약 문단 |
| 글꼴 | 워드의 한글 글꼴(맑은 고딕) |
| 기호 누수 | `**`·`#`·파이프 표·격자 문자열·생각 표시가 글자로 남았나 |
| 표 · 머리줄 | 표가 있나, 첫 줄이 값이 아니라 열 이름인가 |
| 빈칸 속임 | 「확인 불가」류로 채운 칸 |
| 출처 | 행마다 주소 |
| **근거** | 파일 속 숫자·주소가 **그 판에서 실제로 읽은 원문**에 있나 |

근거 대조는 정답표를 사람이 만들지 않는다. 판의 장부(도구가 돌려준 숫자·본문 숫자·연 주소)와 대조한다.

- 숫자 정규화는 [evidence-ledger](https://github.com/KIMDONGJU021211/evidence-ledger) 의 `numbers_claimed_in` —
  장부 쪽과 **같은 함수**다. 한쪽만 「432쪽」을 432 로 읽으면 거짓 고발이 나온다
- 주소는 경로에 식별 숫자가 있으면 경로로, 없으면 **적은 주소의 파라미터가 연 주소에 모두 있어야** 같은 페이지로 본다
  (`?pcode=`·`?rec_idx=` 를 버리면 아무 주소나 통과하고, 통째로 견주면 곁가지 파라미터로 오탐이 난다)

## 새 과제 검사의 규칙

1. 과제를 **결과 보기 전에** 커밋한다
2. 결과를 보고 과제를 바꾸지 않는다
3. 망하면 망한 대로 남긴다
4. 고치더라도 **그 과제로 다시 재서 숫자를 올리지 않는다** — 그러면 그것도 튜닝 대상이 된다. 다음 검사는 또 새 과제로

## 채점기 자신의 검사

새 눈금은 붙이기 전에 **양쪽 표본**으로 확인한다 — 좋은 파일을 걸면 오탐, 나쁜 파일을 통과시키면 눈금이 아니다.
지어낸 쪽수·안 연 주소·값인 머리줄·별표 누수·틀린 형식은 걸려야 하고, 멀쩡한 마크다운·워드·한글·CSV 는 통과해야 한다.
